# FoodDelivery Operator Panel

Фронтенд панели оператора для лабораторной работы с Spring Boot, PostgreSQL и Riak KV.

## Запуск

```bash
npm install
npm run dev
```

По умолчанию API ожидается на `http://localhost:8080`. Другой адрес можно указать в `.env.local`:

```text
VITE_API_URL=http://localhost:8081
```

Тестовый логин: `operator1`.
